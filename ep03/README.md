# Episode 3 – Classes and Objects

The heart of Java: a class is a blueprint, and an object is a real thing built from it.

**You'll learn:**
- How to write a class with fields (what it has) and methods (what it can do)
- How to create objects with `new`
- How each object keeps its own data
- Why forgetting `new` causes an error
