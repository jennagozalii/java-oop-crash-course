# Episode 6 – Inheritance

Write code once in a parent class, and reuse it in every child: the second pillar of OOP.

**You'll learn:**
- How `extends` makes TutorBot inherit everything from ChatBot
- How `super(...)` passes data up to the parent's constructor
- The difference between `private` and `protected`
- Adding new fields and methods only the child has
