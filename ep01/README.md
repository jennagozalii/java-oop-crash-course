# Episode 1 – How to Install Java in VS Code

Set up everything you need to write Java, then run your first program.

**You'll learn:**
- What the JDK is, and how to install Eclipse Temurin 25
- How to set up VS Code with the Extension Pack for Java
- The structure of a Java program: class, main method, println
- Two beginner mistakes: a missing semicolon, and a class name that doesn't match the file name
