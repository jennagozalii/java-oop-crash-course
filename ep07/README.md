# Episode 7 – Interfaces and Polymorphism

How apps can swap between AI models without being rewritten: abstraction and polymorphism, the last two pillars of OOP.

**You'll learn:**
- What an interface is: a contract that says what a class must do, not how
- How `implements` and `@Override` work
- Polymorphism: one method call, different behaviour for each object
- The for-each loop
- Why code that depends on an interface is easy to extend
