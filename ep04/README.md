# Episode 4 – Constructors and Methods

Build an object in one line, and teach Nova to answer questions.

**You'll learn:**
- What a constructor is, and how it sets up a new object
- What `this` means (this object's own field)
- Methods that take input (parameters) and give back a result (return)
- Why return is often more useful than printing
